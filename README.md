# UJJWAL AI CALL ASSISTANT

A starter Android project for a Hindi + English AI call-assistant interface.

## Current status
- Android Kotlin starter app
- Hindi / English greeting using Android Text-to-Speech
- Assistant ON/OFF demo control
- Premium dark interface

## Important limitation
This starter is a UI and text-to-speech demo only. It does **not** automatically answer or capture audio from normal SIM calls. Real SIM-call handling requires Android's supported dialer/telecom integration, user-selected default dialer role, and device/carrier-compatible call-audio capabilities. Do not claim call automation until it has been implemented and tested on the target phone.

## Build
Open this repository in an Android Gradle build environment with JDK 17 and Android SDK 35, then build the app module.
